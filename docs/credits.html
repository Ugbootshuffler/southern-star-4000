Optional BOM data (off by default)

The “BOM data (personal use only)” setting makes your browser fetch observations, forecast text and warnings directly from the Bureau of Meteorology’s app API (api.weather.bom.gov.au). That API is not an open-data service: its responses state it is owned by the Bureau and must not be used, copied or shared. It is therefore switched off by default and offered only for your own personal use. Data © Commonwealth of Australia, Bureau of Meteorology. For licensed access see BOM data services.
